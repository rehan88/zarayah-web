For grown-ups

Unplugged Play makes calm, offline games for children: the kind of game you're happy to hand over on a long journey.

  • 🚫 No advertsNone at all, and no links out to websites.
  • 📴 Plays offlineNo internet is needed to play, and the game doesn't go online. The only exception: when you tap Check for updates in Settings, the app asks this website whether there's a newer version.
  • 🔒 Nothing collectedNo accounts and no tracking. Saved games and photos stay on the tablet.
  • 🛍️ Nothing to buyThe game's shop uses coins found while playing, never real money.
  • 💬 No strangersEveryone in the game is a friendly character in the town, never another player.
  • ⏸️ Easy to pausePause any time; the game saves itself as you play.

How to install

The game comes from this website, not the Play Store, so Android asks once whether it may install it.

  1. On the tablet or phone, tap Download for Android above.
  2. Open the downloaded file. The first time, tap Settings, turn on Allow from this source, then go back.
  3. Tap Install, then Open. That's it: it plays without internet from now on.

To update, open ⚙️ Settings in the game and tap Check for updates (from version 1.0.2), or download and install the new version the same way. Your child's saved game and photos are kept.
